## 一句话定位

不做缩小版 Microsoft Project，而是把**项目计划、实施过程、风险问题、交付资料和 AI 助手**整合为一个自托管的个人项目管理工具；项目管理业务数据由系统可靠管理，AI 只辅助、不充当事实来源；先把一个项目从启动、计划、实施、风险处理管理到验收收尾的闭环跑通，再扩展更多工具。

## 核心结论速览

1. **范围**：第一版（P0）= 项目管理 + WBS/任务依赖/甘特图 + 风险/问题/里程碑/进度快照 + AI 助手（WBS 生成、风险分析、周报生成）。P1（干系人、交付资料、Excel/Word 导出、项目收尾）在核心闭环稳定后纳入；P2 不作为开发阻塞项。
2. **开源复用**：Frappe Gantt（MIT，可直接依赖，React 封装层需自研——社区 `react-frappe-gantt` 已停更不可用）；OpenProject（GPL-3.0）、Plane（AGPL-3.0）、Taiga 仅借鉴设计，不引入任何代码。
3. **图表库调研结论（实测）**：`frappe-charts` npm 包停更近 5 年（最新 1.6.2 发布于 2021-06）；`echarts` 6.1.0（2026-05 发布，Apache-2.0）持续维护。建议图表库选 ECharts，**待用户确认（决策项 D-02）**。
4. **两条铁律**（源自规格引言）：业务数据由系统管理、AI 只辅助；先跑通单项目全生命周期闭环，再扩展工具。
5. **工作量估算**（净开发，不含用户评审等待）：阶段 1-6 共 70 项任务，合计 **107 - 161.5 小时**；P0 最小闭环路线（61 项，不含 9 项 P1 任务）约 **91.5 - 137.5 小时**（见 07 文档）。
6. **本规划包完成后停止，等待评审**，不自行跳过规划进入编码。
