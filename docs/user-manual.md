# Project Toolkit 用户操作手册

> 版本：1.0（阶段 6 交付） ｜ 访问地址：http://localhost:8180（本机自托管，端口仅绑定 127.0.0.1）
> 适用：个人项目经理（信息化集成交付场景）

## 1. 工作台总览

- **左侧导航**：项目列表 / AI 工作台 / 系统设置
- **项目空间**：从项目列表点「查看」进入，12 个模块（WBS / 甘特图 / 里程碑 / 计划基线 / 风险 / 问题 / 变更 / 干系人 / 交付资料 / 燃尽图快照 / 报告中心 / 审计日志）
- 所有数据保存于服务器数据库：刷新浏览器、重启容器后数据均在

## 2. 项目管理

1. 「项目列表 → 新建项目」填写编号/名称/客户/项目经理/阶段/状态/计划起止。
2. 编号全局唯一且删除后不释放；重复编号会有明确提示。
3. 归档：从默认列表隐藏（可在"仅归档"视图找回）；删除为软删除（审计日志留痕）。
4. 列表支持搜索（编号/名称/客户）、状态筛选、排序、分页。

## 3. WBS 任务分解

- **建任务**：「新建顶级任务」或任务行「子任务」；支持多级父子。
- **编码**：WBS 编码（1 / 1.1 / 1.1.1）自动计算，增删、上下移动后全树重算，任务 ID 永不变。
- **进度**：叶子任务手工录入进度；父任务自动汇总（工时加权，无工时等权重，可在设置调整）。行内"汇总"标签表示该进度由子任务计算。
- **依赖**：右上「依赖」按钮管理前置→后置；形成循环会被拒绝。
- **Excel**：导出全部任务；导入按 wbs 挂父级，错误行返回行号与原因。
- **工期**：跨周六日的任务自动按工作日历算工期（阶段 2，工作日历可在设置配置）。

## 4. 甘特图

- 日 / 周 / 月三种视图；任务条显示进度，依赖连线自动绘制。
- **拖动任务条改期、拖动进度条改进度**：自动保存（经后端校验；非法日期会弹回并提示）。
- 与 WBS 完全同源：任一端修改，另一端即时一致。

## 5. 里程碑与计划基线

- 里程碑：计划/实际日期与状态。
- 基线：点「保存当前计划为基线」（版本自动递增）；此后修改任务**不会**影响基线；「与当前计划对比」逐任务显示日期/工期/进度差异。

## 6. 风险 / 问题 / 变更

- 风险：概率×影响自动评分定级（低≤4/中≤9/高>9，可在设置调阈值）；页面顶部矩阵热力图直观展示。
- **评估历史**：每次评估追加记录（含依据），当前评分同步更新。
- **转化**：风险可一键转「问题」或「行动任务」，原始风险记录永久保留（状态标记已转）。
- 问题：关闭时**必须填写解决结果**；支持"仅逾期"筛选。
- 变更：记录原因/范围/工期影响与审批状态流转。
- 干系人：登记影响力/关注度，记录每次沟通（渠道/内容/结论/后续行动）。

## 7. 燃尽图与进度快照（BR-03）

- 任务有写操作时系统自动记录当日快照；也可点「记录今日快照」手动采集；支持补录历史日期。
- 燃尽图只基于真实快照绘制（任务数/剩余工时双口径 + 理想线）；**没有记录的历史不会画线**。

## 8. 交付资料

- 选择模板一键实例化（设备到货/安装调试/测试/培训/试运行/验收/运维移交）。
- 维护责任人/计划完成/提交状态/审核状态；可上传附件（≤50MB）。
- Excel 导入导出；「AI 缺失检查」需先配置模型（见第 10 节）。

## 9. 报告中心

- 「导出周报 Word」：含任务明细表、风险问题汇总；正文自动带统计截止日期/数据来源/生成时间。
- 「导出收尾报告 Word」：完成情况、里程碑、交付清单表、风险问题计数。
- AI 工作台中的「周报初稿」可生成可编辑文本稿（需模型配置）。

## 10. AI 工作台与模型配置

1. 「系统设置 → AI 模型配置」填写任一 **OpenAI 兼容**服务：
   - Base URL（如 `https://api.deepseek.com/v1`）、模型名（如 `deepseek-chat`）、API 密钥、超时。
2. 点「连接测试」验证 → 「保存配置」。密钥仅存服务端，界面只显示掩码。
3. AI 工作台能力：**WBS 初稿**（生成后进建议中心，确认前不落库）、工期/依赖检查、风险建议、周报初稿、项目问答。
4. **铁律**：AI 产物必须经你在「建议中心」点「确认应用」才会写入业务数据；拒绝则零改动。高影响操作（如批量改期）会再要一次确认。
5. 未配置模型时，其余全部功能不受影响。

## 11. 审计日志

- 项目空间「审计日志」记录全部关键操作（创建/更新/删除/归档/关闭/评估/AI 确认等），支持按操作类型、对象类型筛选。

## 12. 日常使用建议

- 每日打开系统，任务状态变更会自动留燃尽快照。
- 重大变更前手动备份：`bash scripts/backup.sh`（见备份文档）。
- 模型配置好后先用「项目问答」试一两个问题确认上下文正常。
